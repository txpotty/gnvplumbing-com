    Waterless Urinal Installation in Middletown

    Waterless urinals save the most water and need the most discipline. They use a cartridge or a layer of sealing liquid that lets urine pass while blocking sewer gas, and the cartridge has to be swapped on schedule or the restroom starts to smell. Your custodial team needs training. We show them how.

    Sensor Urinal Installation in Middletown, DE

    Sensor valves stop missed flushes and double flushes. Battery or hardwired valves get a tuned sensing range and an optional sanitary flush for idle periods. Expect years between battery changes. Hardwired units need an electrician first.

    ADA Urinal Installation in Middletown

    Accessible urinals start at the carrier. We set the carrier so the finished rim lands at 17 inches or lower, keep the clear floor space free of partitions and door swings, and mount the flush handle or sensor where a seated user can reach it. We measure the rim twice. Inspectors measure too.

    Flushometer Urinal Installation in Middletown

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handle side follows the layout. ADA units need the handle within reach.

    Waterless Cartridge Urinals in Middletown

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. A replacement schedule comes with the install. Spare cartridges should stay on site.

    Residential Urinal Plumbing in Middletown, DE

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Commercial Urinal Installation in Middletown

    Offices and restaurants want urinals that survive heavy use. We set vitreous china units on floor-mounted carriers, connect them with new outlet gaskets and stainless bolts, and pair them with a Sloan or Zurn flush valve sized to the bowl. Partitions get spaced to code. Most codes want 15 inches from centerline to the side.

    Sloan Flush Valve Installation in Middletown, DE

    Sloan Royal valves are on most commercial urinals we see. We install them with the correct inside parts kit for the bowl's rated volume, set the control stop so the flush is strong without splashing, and keep rebuild kits on the truck for later service. Sensor versions mount the same way. Battery models need no wiring.
