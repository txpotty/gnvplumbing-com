    Rough-In Plumbing for Urinals in Edgemoor, DE

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    Residential Urinal Installation in Edgemoor, DE

    Basement and garage bathrooms are where most home urinals go.     ADA-Compliant Urinal Installation in Edgemoor

    At least one urinal in a public restroom with more than one usually has to be accessible.     Sensor Urinal Installation in Edgemoor, DE

Expect years between battery changes. Hardwired units need an electrician first.
